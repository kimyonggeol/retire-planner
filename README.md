# 노후 준비 계산기 (웹앱)

## 파일 구성
| 파일 | 역할 |
|---|---|
| index.html | 화면 구조와 디자인 (다크모드 포함) |
| engine.js | 계산 엔진 (세금·4대보험·국민연금·직역연금·퇴직급여·개인연금·주택연금·진단) |
| app.js | 입력 단계, 결과 탭, 저장·백업 |
| manifest.json, sw.js | 앱 설치와 오프라인 동작 |
| icons/ | 앱 아이콘 |

## GitHub Pages로 올리기
1. github.com 가입 후 오른쪽 위 **＋ → New repository**
   - 이름 예: `retire-planner` · **Public** 선택 · Create
2. 저장소 화면에서 **uploading an existing file** 클릭
   - 압축을 푼 폴더 안의 파일과 `icons` 폴더를 통째로 끌어다 놓기 → **Commit changes**
3. **Settings → Pages**
   - Source: **Deploy from a branch** · Branch: **main** / **(root)** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/retire-planner/` 주소가 생깁니다.

> 코드만 공개되고, 각자 입력한 값은 그 사람 폰 브라우저에만 저장됩니다.

## 폰에 설치
- **갤럭시 (Chrome / 삼성 인터넷)**: 주소 열기 → 첫 화면의 **홈 화면에 앱 설치** 버튼, 또는 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**
- **아이폰 (Safari)**: 주소 열기 → 아래 **공유 버튼(□↑)** → **홈 화면에 추가**
  - 아이폰은 반드시 Safari로 열어야 합니다 (카카오톡 안 브라우저에서는 설치 불가)

## 수정 후 다시 올릴 때
`sw.js` 맨 위 `VERSION = "rp-1.1.0"`의 숫자를 올린 뒤 파일을 다시 업로드하세요.
폰에서는 앱을 한 번 닫았다 열면 새 버전이 적용됩니다.

## 계산 기준 (근사치)
- 국민연금: 2025년 개정법(보험료율 9.5%→13%, 상수 1.29), 가입 10년 미만 0원, 조기 −6%/년·연기 +7.2%/년
- 공무원·사학연금: 지급률 2035년까지 1.7%로 하향, 재직 10년 이상, 최대 36년 / 군인연금 1.9%, 20년 이상 전역 즉시
- 퇴직급여: DB(평균임금×근속, 회사 규정 a×n±b 선택 가능 · 법정 미만이면 법정), DC(임금총액×부담률 운용), 공무원 퇴직수당(6.5~39%), 연금수령 시 퇴직소득세 30% 감면
- 은퇴 후 건강보험: 지역가입자 근사(공적연금 50% + 주택 재산분), 배우자 근로 중이면 피부양자로 0원
- 주택연금: 종신 정액형 1억원당 월 지급액 근사표 — 정확한 금액은 한국주택금융공사 조회
